# Dinesh's Portfolio

A React portfolio built with Vite.

## Run locally

```sh
npm install
npm run dev
```

## Update portfolio content

Edit [`js/content.js`](./js/content.js) to update the name, introduction, about text, projects, experience, certifications, skills, email, and contact links. Leave the email blank until you want to publish one. Leave experience or certification lists empty until you have details to add; no sample entries are displayed.

Update the visual styles in [`css/style.css`](./css/style.css). The site supports light and dark themes and follows the operating system theme unless a choice has been saved in the browser.

## Validate and build

```sh
npm run lint
npm run build
```
